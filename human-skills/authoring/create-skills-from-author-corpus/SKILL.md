# 人物の著作群からHuman Skillsを作る

## こんなとき

思想家、作家、研究者、経営者など、ある人物の著作、講演、書簡、自伝、日記などをまとまって読み、その中に繰り返し現れる考え方や判断方法を、複数のHuman Skillsとして再構成したいときに使います。

人物紹介、思想史、名言集、著作要約を作ることが目的ではありません。その人物の文章を材料にしながら、最終的には「誰の言葉か」を知らなくても学べる、匿名の独立したHuman Skillsを作りたい場合に向いています。

## どうする

最初からSkillを書き始めず、まず著作群全体を横断して、繰り返し現れる問題の捉え方、判断基準、行動原則、失敗への向き合い方、価値の衝突などを集めます。一冊の有名な作品、一つの名言、一つの印象的な一節だけを根拠に、その人物の考え方全体を決めません。

特に次のような問いを使って材料を探します。

- 何を良い状態、悪い状態と見なしているか
- 困難や不確実性に直面したとき、何を基準に判断しているか
- 学習、仕事、他人、社会、失敗、成功などをどう捉えているか
- 同じ問題について、別の著作でも似た判断をしているか
- 抽象的な主張を、具体的な場面ではどう扱っているか
- どのような誤りや弱さを繰り返し警戒しているか
- 時期や状況によって考えが変化しているか
- 本人の主張の中に、両立しにくい緊張関係がないか

候補を見つけても、すぐに「○○を大切にする」のようなSkillにはしません。その考え方によって、人が具体的に何を見分け、何を判断し、何を変えられるのかを掘り下げます。

たとえば「権威を盲信しない」という考えを抽出した場合、それだけでは薄すぎます。肩書きと根拠をどう分けるのか、どんな証拠を確認するのか、自分で検証できない部分をどう扱うのか、判断を保留すべき状態は何か、逆に専門家の知見を軽視する誤りをどう避けるのか、といったところまで整理できて初めて学びのあるSkillになります。

各候補は、可能な限り複数の著作や異なる文脈で確認します。単独の記述しかない場合は、人物全体を代表する原則として過度に一般化しません。逆に、何度も現れる考えでも、単なる標語としてしか抽出できない場合は公開用Skillにしません。

矛盾や変化は消しません。初期と後期で考えが違う場合、状況によって別の判断をしている場合、同じ価値同士が衝突している場合は、無理に一つの綺麗な原則へ統合しません。必要なら「この条件ではこちらを優先する」「この考えにはこの限界がある」という形でHuman Skillの中へ落とし込みます。

歴史的な語彙、当時の制度、本人固有の比喩は、そのまま現代の行動指針にしません。まず、その文章が扱っていた問題の構造を考えます。その構造が現代にも再利用できる場合だけ、現代の読者が理解できる自然な言葉へ書き直します。時代固有の前提が不可欠で一般化できない内容は、無理にHuman Skill化しません。

候補は細かく分けすぎません。一文の格言ごとにSkillを作ると、Human Skillsが薄いTips集になります。独立した場面で使え、単体で十分な学習内容を持てる単位へまとめます。一方で、異なる問題を扱う内容を「人生哲学」のような巨大な一つのSkillへ押し込みません。

Skill候補を公開対象にする前に、次を確認します。

- 人物名を消しても学ぶ価値があるか
- 単なる常識や自己啓発の標語ではないか
- 読者の見方や判断が具体的に変わるか
- なぜそう考えるのかを説明できるか
- 実際の場面で何を観察すればよいか分かるか
- 条件、例外、反例、失敗のどれかが重要なら、それを説明できるか
- 他の候補とほぼ同じ内容ではないか
- 数行のTipsではなく、一つの学習単位として十分な密度があるか

この段階で弱い候補は、追加で著作群を調べる、近い候補と統合する、または捨てます。大量のSkillを作ることより、少数でも内容の濃いSkillを作ることを優先します。

最終的なHuman Skillでは、元になった人物の名前、作品名、著者名を、由来を示す目的では書きません。`derived_from`、出典人物、系譜、引用元一覧などの独自メタデータも追加しません。Human Skills本体の既存YAMLフォーマットをそのまま使います。

新規Skillでは `id` と `author` を生成しません。人物由来であることを示すためのauthorも設定しません。Human Skillsへimportしたときにサービス側で扱われる既存仕様に従います。

本文は `## こんなとき`、`## どうする`、必要なら `## 補足` だけで構成します。それぞれの内部で `###` などの追加見出しは使いません。内容が長い場合は段落、箇条書き、番号付きリストで整理します。

完成した各Skillは、人物の著作を一度も読んだことがない人だけに渡すつもりで読み直します。それでも、何を学べるのか、なぜそうするのか、どんな場面でどう使うのかが分かる状態にします。

## 補足

人物の著作からHuman Skillsを作ることは、その人物を正しい答えとして採用することではありません。長い著作群の中で繰り返し試されてきた問題の捉え方や判断パターンのうち、現在でも学習素材として価値があるものを取り出す作業です。

現代の知識や倫理と衝突する部分、事実として誤っている部分、時代依存が強い部分は、そのまま教訓として採用しません。重要なのは人物への忠実な礼賛ではなく、原典を十分に読んだうえで、人が学べる中身へ再構成することです。
